# BOTIQUIN-DE-CONFIANZA
Sistema Java de gestión inteligente de medicamentos para botiquín doméstico o pequeño. Elimina tres problemas clásicos: medicamentos vencidos sin retirar, pastillas agotadas sin aviso y confusión entre presentaciones distintas. Sabe qué tiene, cuánto, en qué orden usarlo y cuándo reponer — sin rastreo manual.
